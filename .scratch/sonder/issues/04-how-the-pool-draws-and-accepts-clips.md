# How the pool draws and accepts clips

## Question

How does the seeded pool draw clips into the chapter, and how do optional contributions join it?

Constraints already locked: it must work solo from a seed; filming can add a clip; a return draws a different mix; the contributor is not labeled on replay. Use [Research Motto's loop](01-research-mottos-loop.md) before answering.

## Answer

The pool is silently grouped by Presence and drawn by Motif. This chapter's handful comes from the seed, so it works solo.

Skip still plays those Motif clips — the chapter never depends on you filming. A Presence's second meeting is later in the same chapter, not an instant echo.

Your filmed clip becomes a new Presence for other people, Motif-tagged from the prompt that produced it. It is never shown as yours this visit, and it is never merged onto a seed someone.

A Return is the same handful with different Motif clips. Nobody is labeled. (That implies the seed is deep enough that a Return is not the same files; who films it is still open.)
